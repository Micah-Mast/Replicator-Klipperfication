# Using this config.ini
In PrusaSlicer under the File dropdown, choose **Import** and then **Import Config Bundle** and then navigate to the config.ini in this folder.

# Known Issue
The files for the custom bed texture and model fail to import automatically so they must be applied manually. This is not necessary for the slicer to work but it makes it look nicer.
In the **Printers** menu, click the **Set** button next to **Bed Shape** and import the files with their respective buttons.
